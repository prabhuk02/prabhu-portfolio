# Prabhu Preetham Kota — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — dark UI, responsive layout, timeline and project cards
- `script.js` — section navigation and LinkedIn URL configuration
- `assets/profile.jpg` — put your profile photo here
- `assets/resume.pdf` — put your resume PDF here

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing
1. Add your photo as `assets/profile.jpg`.
2. Copy your resume PDF to `assets/resume.pdf`.
3. Add the full LinkedIn URL to `linkedinUrl` in `script.js`.
4. Verify each project status and add individual repository URLs if available.
5. Do not commit passwords, access keys, or other secrets.
